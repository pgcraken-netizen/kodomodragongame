# 子どもドラゴンのワクワクタウン

スマートフォン縦画面向けの、子ども（3〜10歳）と保護者のための探検ゲーム。子どもドラゴンと町を歩き、人形劇やキャンプのおてつだいをします。提供された原画を使った開発用ドラフトで、団体の正式な監修・使用許諾は別途確認が必要です。

- 仕様・現状：`GAME_SPEC.md`（統合開発要件仕様書 v3.2）
- 参考画像：`docs/reference/`

## 起動
ビルド不要の静的サイトです。`python3 -m http.server 8000` を実行し、http://localhost:8000 を開きます。Vercel では Framework Preset を Other、ビルドなし、出力はルートにします（`main` への push で自動デプロイ）。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 状態・ミッション・ゾーンの基本定義、読み込み順 |
| `art.js` / `kd.css` | 共通の絵（アイテム・なかま・アイコン・クレヨン調フィルタ）、ゾーンと扉の座標、次の行き先、ポップアップ |
| `adventure.js` | レシピ・会話・サブイベント定義、保存、設定 |
| `controls.js` | 町の移動・カメラ・扉の自動入場・十字キー/A/B |
| `world.js` | 町の絵、横スクロールの薪あつめ |
| `town-overlay.js/.css` | 町のHUD・メニュー・行き先案内・効果音 |
| `interiors.js/.css` | 9ゾーンの室内／屋外シーン（歩いて、さわって、アイテムを取る） |
| `scenes.js/.css` | 人形劇・料理・星空・花火・ずかん・あそびかた |
| `assets/` | 表紙・町・森・歩行スプライト・原画 |

## テスト
```
python3 -m http.server 8000 &
node test-e2e.cjs [スクリーンショット保存先]
```
Playwright と Chromium が必要です。表紙から両方の話・寄り道・星空・花火・保存再開まで通しで確認します。
